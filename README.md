# medicare_hms_backend

MediCare API backend built with Node.js, Express, and MongoDB.

## Run locally

1. Install dependencies with `npm install`.
2. Configure `PORT`, `MONGO_URI`, `RAZORPAY_IDKEY`, and `RAZORPAY_SECRET_KEY` in a local `.env` file.
3. Start the API with `npm start`.

The `.env` file contains private credentials and is excluded from Git. Configure the same variables in the backend hosting provider's environment settings.
